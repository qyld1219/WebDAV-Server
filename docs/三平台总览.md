# WebDAV 服务器 · 三平台总览

同一套开源内核，三个平台三种外壳，都是「把本机变成标准 WebDAV 服务器 + 远程访问」。

| 平台 | 交付物 | 界面 | 服务端内核 | 隧道内核 | DDNS | 验证状态 |
| --- | --- | --- | --- | --- | --- | --- |
| macOS 14+ | `WebDAV服务器-1.0-arm64.dmg` / `WebDAV服务器.app` | SwiftUI 原生窗口 + 菜单栏 | hacdias/webdav v5.17.3 `darwin-arm64` | cloudflared 2026.10.7 | ✅ | 全流程实测（含公网隧道） |
| Windows 10/11 x64 | `WebDAVServer-Windows-x64.zip` → `WebDAV-Server-Windows/WebDAVServer.exe` | 本地网页控制台（自动打开浏览器） | 同版本 `windows-amd64` | 同版本 `windows-amd64` | ✅ | 同源逻辑在 darwin 构建上端到端实测（含公网隧道） |
| Android 8+ arm64 | `WebDAVServer-android-arm64.apk` | 单页原生控件 + 前台服务 | 同版本 `linux-arm64`（以 `libwebdav.so` 打包） | 同版本 `linux-arm64` | ❌ | APK 构建/签名/内核入包已核验；运行时未在真机或模拟器执行（本机模拟器镜像下载过慢，已放弃） |

## 三条远程访问路径的覆盖情况

- **快速隧道（Cloudflare，免账号）**：三端都有。
- **自有域名（命名隧道）**：macOS 与 Windows 有；Android 未做（手机不适合长期持有固定域名隧道）。
- **DDNS + 端口映射**：macOS 与 Windows 有；Android 未做（手机通常拿不到公网入向）。
