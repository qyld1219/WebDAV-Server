# WebDAV 服务器 · 功能介绍

一句话：把 Mac / Windows 电脑或安卓手机变成一台标准 WebDAV 服务器，配一条公网 HTTPS 地址，随时随地读写本机文件。

---

## 核心功能

**1. 一键把本机变成 WebDAV 服务器**
选一个文件夹、设一个端口、填一组账号密码，点「开始共享」就完成。协议是标准 WebDAV，访达、资源管理器、iOS 文件 App、Cyberduck、nPlayer 等客户端都能直接连。

**2. 完整读写，不是只能下载**
支持列目录、上传、新建文件夹、覆盖、删除、重命名、加锁（PROPFIND / PUT / MKCOL / DELETE / LOCK 均已实测）。也能开启只读模式，只允许别人下载。

**3. 网页文件列表**
浏览器直接打开地址就能看到文件列表、点开下载，不用装任何客户端。

**4. 局域网零配置**
同一 Wi-Fi 下，界面直接给出 `http://本机IP:端口` 地址和二维码，手机扫码即连。

**5. 三条远程访问通道**

| 通道 | 适合场景 | 是否需要额外条件 |
| --- | --- | --- |
| Cloudflare 快速隧道 | 临时把文件分享给外网的人 | 不需要账号、不用改路由器，一键生成 `https://xxx.trycloudflare.com` |
| 自有域名 + 命名隧道 | 长期自用，地址固定不变 | 需 Cloudflare 账号与域名，配一次 Public Hostname 即可 |
| DDNS + 端口映射 | 家里有公网 IP、想直连 | 需路由器端口转发 + Cloudflare API Token |

隧道都自带 HTTPS；公网访问不再靠明文 HTTP。

**6. 内置容错，不用自己排障**
- 本机 QUIC 不通时，自动切 HTTP/2 重连；
- Cloudflare 限流（429）直接给出可读提示，而不是「进程退出」；
- 端口被占用、上次异常退出的残留进程，程序自己回收，不会偷偷把服务暴露在公网。

**7. 常驻与自动化**
菜单栏 / 通知栏常驻；服务运行期间阻止系统休眠；支持开机自启、打开即共享；密码与 Token 存系统钥匙串。

## 三平台覆盖

| | macOS | Windows | Android |
| --- | --- | --- | --- |
| 界面 | 原生窗口 + 菜单栏 | 本地网页控制台 | 单页 App + 前台服务 |
| 局域网共享 | ✅ | ✅ | ✅ |
| 快速隧道 | ✅ | ✅ | ✅ |
| 自有域名隧道 | ✅ | ✅ | ❌ |
| DDNS | ✅ | ✅ | ❌ |
| 账号鉴权 / 只读 / 网页列表 | ✅ | ✅ | ✅ |

安卓端只做「手机当服务器 + 快速隧道」——手机不适合长期持有固定域名隧道，也基本拿不到公网入向。

---

## 典型用法

- 出差时用手机、借用别人的电脑，取回放在家里 Mac 上的项目文件；
- 把手机里的照片、录音以 WebDAV 形式挂到电脑上，当移动硬盘用；
- 给同事临时分享一个大文件，发一条 `https://` 链接就完事，不用上传网盘；
- 在自己的 NAS 之外，把笔记本变成一台随手可用的文件服务。

## 技术底座

不自己写协议栈，直接打包成熟开源内核：

- 服务端：[hacdias/webdav](https://github.com/hacdias/webdav) v5.17.3（MIT，Go 静态二进制）
- 隧道：[cloudflared](https://github.com/cloudflare/cloudflared) 2026.10.7（Apache-2.0）
- 外壳：macOS 用 SwiftUI，Windows 用 Go + 本地控制台，Android 用原生 Java

---

## 需要知道的限制

- 电脑关机、合盖休眠、手机被系统省电策略杀掉，远程访问就会断；
- 快速隧道的地址每次重启都会变，要固定地址请用自有域名；
- 公网暴露请务必保留账号密码，必要时开只读；
- macOS 版为本地签名，首次打开需右键「打开」；Windows / Android 为未签名/调试签名包，安装时允许未知来源即可。
